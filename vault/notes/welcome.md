# Welcome to mindbase

Your vault works **offline** — notes and databases are stored on disk.

- Edit pages and databases as **markdown** (autosave after ~800ms)
- Databases are stored as CSV; edit them as markdown tables
- Press **Save** or wait for autosave to write to disk
- Go core starts in the background for live preview when available
